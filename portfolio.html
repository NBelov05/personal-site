DevPocket — органайзер кода и технических заметок

C# · .NET 10 · Avalonia UI · SQLite (WAL) · TextMate

ЗадачаСоздать 100% автономное desktop-приложение для разработчиков: быстрый доступ к сниппетам кода, техническим заметкам и шаблонам без серверов, облаков и телеметрии.
РешениеПриложение на C# / .NET 10 с MVVM-архитектурой и кроссплатформенным GUI на Avalonia UI 12. Встроен редактор кода с подсветкой синтаксиса TextMate для 24 языков, локальная база SQLite с миграциями, многокритериальный поиск и горячие клавиши.
РезультатМолниеносный запуск, оффлайн-работа, экспорт в файлы с правильными расширениями, связывание заметок со сниппетами и надёжное локальное хранение данных.

Бот-парсер каналов с AI-суммаризацией

Python · aiogram · SQLite · DeepSeek API

ЗадачаАвтоматически забирать посты из публичных Telegram-каналов и готовить по ним краткие русскоязычные резюме и дайджесты.
РешениеTelegram-бот на aiogram: HTTP-парсер публичных лент, SQLite-хранилище, суммаризация через DeepSeek API с ретраями, фоновый планировщик sync + analyze по подпискам, команды latest/digest/status.
